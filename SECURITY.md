# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use GitHub's private vulnerability reporting feature for this repository.

Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge a complete report as soon as practical.

## Scope

Astra Prompt Studio generates prompts locally in the browser and does not require an API key. Reports about accidental data transmission, unsafe dependency behavior, cross-site scripting, or leaked deployment credentials are in scope.
